Connecting Mr. Milk with MilkMaster

A simple guide — what we want, and what we need from MilkMaster. Prepared for Aniket.

What we want, in one line: our daily sales data from MilkMaster should flow into the Mr. Milk app automatically — so nobody has to download and upload files by hand.

The simple idea

📄→📤
Today
Someone exports a file and uploads it by hand, every time.
➜
🔑🤖
After we connect
The app fetches the new data on its own, every day.

Think of it like giving the app a key to read the data, so a little robot can collect the new sales each night — no manual work, never out of date.

What we’re asking MilkMaster for

We don’t need to know your technology or database. Any one of these three works — please pick whichever is easiest for you:

1

An API key BEST

A secure, read-only “password” that lets our app pull the sales data directly. Fully automatic and always fresh.

2

A daily auto-export file EASIEST

MilkMaster automatically drops a daily sales file (CSV/Excel) into a folder, Google Drive, or email — and our app picks it up by itself.

3

Read-only access to the data

Only if the first two aren’t possible — a read-only view of the sales records. (This is the only option where your database type matters.)

The few questions to ask in the meeting

  1. Do you have an API we can connect to? If yes, please share the link and a read-only key.
  2. If not — can you auto-send a daily sales file to a folder, Google Drive, or email?
  3. Can you give us the sales / delivery history with a date filter (so we only pull new days)?
  4. Can you share one sample of the data so we can confirm the columns?

What data we need (the basics)

DateCustomer (phone / id)Product & pack size QuantityAmount (₹)Delivered / cancelled Hub / areaInvoice id

Is it safe?

Read-only. We only read the data — we never change anything in MilkMaster.
Private key. The key stays on our server, never shared or shown in the app.
You stay in control. MilkMaster can switch off the access anytime.

What happens after

Once we have a key or a file feed, we connect it in a few days. After that, every morning the app already shows yesterday’s sales — dashboards and reports update by themselves, with zero manual uploads.
